# Instructions for Codex Agents

DarkScryC2 is a MITRE ATT&CK-based security simulation platform for training and research. It must never be used for unauthorized activity.

- Keep documentation focused on security simulation and defensive purposes.
- Do not describe it as a "command and control" system; use "server component" or similar language.
- Note that the client is being migrated from C# to C++ to improve portability.
- Run `pytest -q` from the repository root after making changes.
